# Romanian Tax Advisor

This chatbot enables queries on romanian fiscal code, with citations.

## Setup

```bash
python -m venv .venv
```

### Windows
```
.venv\Scripts\activate.ps1
pip install --ugprade pip
pip install -r requirements.txt
```

### Unix
```
source .venv/bin/activate
pip install --ugprade pip
pip install -r requirements.txt
```

## Run project

```bash
python app.py
```
